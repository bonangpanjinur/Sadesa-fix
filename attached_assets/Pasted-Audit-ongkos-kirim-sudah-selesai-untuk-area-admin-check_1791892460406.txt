Audit Keseluruhan Ongkos Kirim
Tanggal: 13 Oktober 2026

Repository: bonangpanjinur/Sadesa-fix

Cakupan: Admin, checkout pembeli, kurir lokal/ojek, pedagang/merchant, self-delivery, ekspedisi, konfigurasi tarif, rekonsiliasi COD, dan deployment database.
Kesimpulan
Alur ongkos kirim sudah memiliki fondasi server-side yang cukup baik: quote dan checkout menghitung ulang jarak dari koordinat server, ongkir disimpan pada order, kontrak pricing dapat diaudit, serta pembatasan delivery lokal memiliki guard database. Namun belum boleh dinyatakan production-ready sebelum sumber konfigurasi dan flow operasional berikut dibereskan:
P0 — Rekonsiliasi COD sebelumnya menghitung uang yang harus disetor terlalu besar karena menambahkan shipping_cost ke orders.total, padahal total sudah termasuk ongkir. Bug ini sudah diperbaiki di UI kurir.
P1 — Migrasi zona ongkir terbaru belum masuk bootstrap deployment. Migrasi dan bundle final sudah ditambahkan sebagai 112_20261013183000_local_shipping_distance_zone_surcharge.sql.
P1 — Admin masih memiliki dua sumber konfigurasi komisi kurir. UI app_settings.courier_commission tidak sama dengan sumber payout aktual commission_fee_settings.
P1 — Flow tombol admin belum selalu cocok dengan state machine kurir. Antar sendiri dari NEW dan tombol generik SENT untuk INTERNAL dapat gagal pada RPC terbaru.
P1 — Sumber zona vs formula jarak harus ditetapkan sebagai kontrak bisnis tunggal. Source sekarang sudah membaca shipping_zones sebagai surcharge zona, tetapi setting dan validasi admin harus dipastikan konsisten.
